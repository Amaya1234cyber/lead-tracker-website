# Privacy Notice — Lead Tracker

**Last updated:** 5 November 2026

Lead Tracker is a local-first Chrome extension. It lets you save website URLs that you want to revisit.

## Information handled

- URLs that you choose to save manually or by selecting **Save current tab**.
- A locally generated identifier and save timestamp for each saved URL.

## Where information is stored

Saved leads are stored in `chrome.storage.local` in your Chrome browser profile. The extension does not send saved leads to a developer-operated server, analytics provider, advertising network, or other third party.

## Import and export

If you choose Import, the extension reads the JSON file you select and adds valid, non-duplicate HTTP/HTTPS links. If you choose Export, it creates a JSON file for you to save. These actions are user-initiated.

## Permissions

- `activeTab` is used to read the current tab URL when you click **Save current tab**.
- `storage` is used to retain your saved leads locally.

## Retention and deletion

Your saved links remain in local extension storage until you remove individual entries, use **Clear all**, or remove the extension/profile data. Exported files are outside the extension's control and must be deleted by you if no longer wanted.
