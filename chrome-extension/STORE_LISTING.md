# Chrome Web Store Listing Draft

## Name
Lead Tracker

## Short description
Save, search, and organize useful links and opportunities right from Chrome.

## Detailed description
Keep important opportunities one click away. Lead Tracker helps you collect useful web pages while browsing, then find them again when you need them.

**What you can do**
- Save a link by pasting its URL or saving the current tab.
- Search your saved links instantly.
- Remove a single link or clear your list after confirmation.
- Export your list to a JSON backup and import it later.
- Keep your saved links in local Chrome storage.

Lead Tracker does not require an account and does not transmit your saved links to a remote service.
